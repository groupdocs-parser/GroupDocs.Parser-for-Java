# GroupDocs.Parser for Java - AGENTS.md

> Instructions for AI agents working with **Java** examples in this repository.

GroupDocs.Parser for Java extracts text, images, metadata, forms, barcodes, and structured content from **65+** document and related formats.

**Supported formats:** **65+** - [https://docs.groupdocs.com/parser/java/supported-document-formats/](https://docs.groupdocs.com/parser/java/supported-document-formats/)

**Human overview:** see [README.md](README.md).

## Install

Maven artifact `com.groupdocs:groupdocs-parser` - set `<version>` from [https://releases.groupdocs.com/parser/java/](https://releases.groupdocs.com/parser/java/).
